# Security policy

Gaia holds its users' credentials, so we treat security reports as the
highest priority.

## Reporting a vulnerability

Report privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Do not
open a public issue, discussion or pull request for a suspected
vulnerability.

Include what you can: the affected version (`gaia --version`), the steps to
reproduce, and the impact you expect.

## What to expect

- An acknowledgement within 3 working days.
- An initial assessment within 10 working days.
- A fix released before the issue is discussed in public. We will agree a
  disclosure date with you and credit you in the advisory unless you ask us
  not to.

## Supported versions

Gaia is pre-alpha. Only the latest commit on `main`, and once releases exist,
the latest release, receive security fixes.
