# fix-0001 — The licences check fails in CI: go-licenses finds no licence for github.com/jmespath/go-jmespath

- **Type:** fix | **Risk:** low | **Priority:** p0
- **Coder:** claude-code/opus-5-5 | **Date:** 2026-11-27
- **Plan:** .metis/plans/phase-0-plan.md Workstream 0.8: Release pipeline and install script

## Goal

Make the CI licence check (Workstream 0.8: "Run `govulncheck` and a licence
check in CI") pass honestly on linux, and check every release GOOS/GOARCH.

## Architectural context

- `make licenses` (Makefile) runs go-licenses v2.0.1 `check ./...` with
  `ALLOWED_LICENSES`; CI job `licenses` in `.github/workflows/ci.yml` runs it
  on ubuntu-latest.
- `github.com/jmespath/go-jmespath v0.4.0` is reached only for GOOS=linux,
  through `internal/net/nettest` → `tailscale.com/tstest/integration` →
  `tailscale.com/ipn/store/awsstore` → `aws-sdk-go-v2/service/ssm`. It is not
  in the dependency set of `./cmd/gaia` (the release binary) on any GOOS.
- Release targets (`.goreleaser.yaml`): darwin, linux, windows × amd64, arm64.
  Archives ship `LICENSE` and `README.md`; SBOMs are syft over each archive.

## Declared file scope

- **owned_paths:** Makefile, .metis/briefs/fix-0001.md
- **read_only_paths:** .github/workflows/ci.yml, .goreleaser.yaml, scripts/check-dist.sh, go.mod, go.sum, internal/net/nettest

## Definition of Done

- `make licenses` runs go-licenses for each release GOOS/GOARCH (the tool is
  built for the host, the check loads packages for the target) and exits 0.
- go-jmespath is kept checked if go-licenses can classify it; otherwise it is
  ignored by exact module name only, with a Makefile comment naming its
  licence and where it was read. `ALLOWED_LICENSES` unchanged; no pattern
  ignores; CI job unchanged.
- SBOM / shipped notices coverage of the module stated in the Report.

## Test plan

- `make licenses` green for all six targets locally (covers the CI linux case).
- Negative proof: the check still fails on a disallowed licence (run once
  with a narrowed allow list, recorded in the Report).
- `metis verify --post` green.

## Out-of-scope touches

None.

## Report

- Changed: `Makefile` only. go-licenses is installed to `.local/bin` (like
  govulncheck) so GOOS/GOARCH select the checked packages; `make licenses`
  loops over the six release targets; `LICENSE_IGNORE` holds
  `github.com/jmespath/go-jmespath` (exact name) with its licence and source
  in a comment. `ALLOWED_LICENSES`, CI job unchanged.
- Reproduced: `make licenses` failed at linux/amd64 with "Did not find
  license for library 'github.com/jmespath/go-jmespath'" (darwin passed,
  as the old host-only CI-equivalent run would on macOS).
- Licence: upstream tag v0.4.0, cloned; its module-zip h1 hash
  `h1:BEgLn5cpjn8UN1mAw4NjwDrS35OdebyEtFe+9YPoQUg=` equals go.sum. LICENSE is
  "Copyright 2015 James Saryerwinnie" + the Apache-2.0 short notice, no
  licence text, so go-licenses cannot classify it; keeping it checked is not
  possible without changing go.mod (out of scope). Apache-2.0 is allowed.
- Ignore reach: `GOOS=linux go list -deps ./...` shows only the package
  `github.com/jmespath/go-jmespath` under that prefix; none on darwin or
  windows; `go list -deps ./cmd/gaia` contains no jmespath on linux.
- SBOM / notices: archives ship LICENSE and README.md only (no third-party
  notice file to update). The module is not in the release binary, so the
  syft SBOM of each archive correctly does not list it.
- `make licenses`: all six targets pass. Negative proof:
  `make licenses ALLOWED_LICENSES=MIT LICENSE_PLATFORMS=linux/amd64` fails
  ("Not allowed license 'BSD-3-Clause' ... 'tailscale.com'").
